# 🌦️ Weather Website

A modern and responsive weather web application built using HTML, CSS, and JavaScript.  
This app provides real-time weather updates, hourly forecasts, and a beautiful UI using the OpenWeather API.

---

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature updates
- ⛅ Dynamic weather conditions
- 💨 Wind speed information
- 💧 Humidity percentage
- 🕒 Hourly forecast section
- 📱 Responsive design for mobile and desktop
- 🎨 Modern glassmorphism UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## ⚙️ How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/mishravartika005/weather_website.git
```

2. Open the project folder

3. Run `index.html` in browser  
   OR use **Live Server** in VS Code

---

## 🌐 API Used

OpenWeather API

- Current Weather API
- 5 Day / 3 Hour Forecast API

Official Website:  
https://openweathermap.org/api
